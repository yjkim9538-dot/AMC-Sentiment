# AMC 증시 컨센서스 대시보드 (Mock)

군인공제회 증권운용1팀이 위탁운용사(AMC)로부터 **국내·해외 증시 컨센서스**를 수집·열람하기 위한
대시보드의 초안(Mock)입니다. **백엔드 없이** 브라우저에서 엑셀을 직접 파싱합니다.

## 사용 흐름

1. **엑셀 양식 다운로드** — 헤더의 `엑셀 양식 다운로드` 버튼으로 양식(`AMC_컨센서스_양식.xlsx`)을 받습니다.
2. **운용사 배포·작성** — 양식을 각 운용사에 배포하고, 운용사가 시트에 컨센서스를 작성합니다.
3. **업로드** — 작성된 엑셀을 `엑셀 업로드` 버튼으로 올리면 4개 뷰가 자동 갱신됩니다.
   (업로드 전에는 샘플 데이터가 표시됩니다.)

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| 국내 통합 | 전 운용사 시장 전망 비교 + 방향성 분포 + KOSPI 목표밴드 평균 + **종목별 매수/매도 의견 집계** |
| 국내 운용사별 | 운용사 선택 → 방향성·목표밴드·Pro/Con + 종목 Top Pick |
| 해외 통합 | 시장 × 운용사 방향성 매트릭스 + 시장별 분포 (행 클릭 시 Pro/Con 펼침) |
| 해외 운용사별 | 운용사 선택 → 6개 시장 카드 (미국/일본/베트남/인도/ACWI/선진국) |

## 엑셀 양식 구조 (3개 시트)

- **국내시장** (운용사당 1행): `운용사명 · 작성일 · 방향성 · KOSPI목표_하단 · KOSPI목표_상단 · Pro(긍정사유) · Con(부정사유)`
- **국내종목** (운용사 × 종목, 자율 선정): `운용사명 · 종목명 · 의견 · 사유`
- **해외** (운용사 × 시장): `운용사명 · 작성일 · 시장 · 기준지수 · 방향성 · 목표_하단 · 목표_상단 · Pro(긍정사유) · Con(부정사유)`

값 도메인: 방향성 = `강세/중립/약세`, 의견 = `매수/중립/매도`.

## 실행 방법

빌드 단계가 없습니다. 다음 중 하나로 실행합니다.

```bash
# 정적 서버 (권장)
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 `index.html`을 브라우저에서 직접 열어도 동작합니다.

## 기술 메모

- `lib/xlsx.full.min.js` — SheetJS(벤더링, 외부 CDN 불필요)
- `js/app.js` — 파싱·집계·렌더링 / `js/sample-data.js` — 샘플 데이터 / `css/styles.css` — 스타일
- 차트 라이브러리 없이 CSS 분포 바로 시각화하여 외부 의존성을 최소화했습니다.
